Pathfinding

Programmation · IA

J'ai codé un système de pathfinding en suivant un tutoriel, pour comprendre comment un agent calcule un chemin à travers une scène en évitant les obstacles.

Les deux vidéos montrent le résultat dans deux configurations différentes. Refaire le code pas à pas m'a permis de comprendre la logique de l'algorithme plutôt que d'utiliser une solution toute faite.

Réalisation
Codé par mes soins à partir d'un tutoriel
Objectif
Comprendre le fonctionnement d'un algorithme de recherche de chemin

Culling

Optimisation · Unity

Le culling consiste à ne pas dessiner les objets que la caméra ne peut pas voir, pour alléger le travail de la carte graphique.

Ici, j'ai testé le système de culling intégré à Unity pour observer son effet dans une scène : les objets sortent ou entrent dans le rendu selon ce que la caméra voit.

Outil
Unity
Approche
Test du culling intégré au moteur
Objectif
Réduire le nombre d'objets rendus à l'écran
